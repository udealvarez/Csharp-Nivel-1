# 💻 Curso de C# - Nivel Inicial (Maxi Programa)

¡Bienvenido/a a mi repositorio del primer nivel de C#! 🚀  
Este espacio recopila todo lo aprendido durante el curso de introducción a C#, donde dimos nuestros primeros pasos en la programación con Visual Studio Code.

---

## 📚 ¿Qué vimos en este nivel?

### 🟢 Introducción al mundo de C#
- ¿Qué es C# y qué lugar ocupa en la programación?
- Configuración del entorno con **Visual Studio Code**.
- Navegación de carpetas y ejecución de programas por consola.
- Videos explicativos, documentación y ejercicios para practicar desde el primer día.

### ✍️ Primeros programas
- Nuestro primer **Hola Mundo**.
- Tipos de datos: `int`, `float`, `double`, `bool`, etc.
- Ejercicios con porcentajes, constantes y algunos trucos útiles 💡.

### ✅ Estructuras condicionales
- Condicionales: `if`, `else if`, `else`.
- Operadores lógicos: `AND (&&)` y `OR (||)`.
- Uso del `switch` con diagramas y ejemplos en código.

### 🔁 Ciclos y bucles
- Estructuras repetitivas: `for`, `while`, `do while`.
- Casos prácticos con diagramas.
- **Ciclos combinados** y el famoso **corte de control** 🪓.

### 📦 Vectores (Arrays)
- Introducción a los vectores: `int[]`, `double[]`, `bool[]`, etc.
- Explicación con diagramas claros.
- Primer contacto con **cadenas de caracteres** (`string[]`).

### 🧠 Funciones
- Uso de funciones para estructurar y reutilizar código.
- Ejercicios integradores aplicando todo lo aprendido hasta ahora.

✔️ Archivos de código por cada clase y ejercicio.

## 🎯 Objetivo del curso
Formar una base sólida en programación estructurada con C#, entendiendo desde cero cómo se piensan los algoritmos y cómo escribir código limpio y funcional.
